# **App Name**: Harsh Cinematic Portfolio

## Core Features:

- Hero Section: Display a full-screen cinematic hero section with a large heading, subheading, professional image with golden frame, and animated buttons.
- About Section: Showcase Harsh's professional background with a descriptive paragraph, resume download, image with golden frame, and animated skill bars.
- Portfolio Showcase: Create a premium grid gallery of video thumbnails with hover animations, category filter tabs, and a 'View Full Editing Materials' button with the link https://drive.google.com/drive/mobile/folders/1qrgBlQ5iJMA-bHcxywdl2Tg7G-D0iKDZ .
- Instagram Feed: Embed an Instagram feed in a grid style with golden hover animations and a 'Visit Instagram Profile' button with the link https://www.instagram.com/harshhk_16 .
- Services Offered: Display premium glass cards with golden borders outlining the services Harsh offers, with smooth hover animations.
- Client Testimonials: Implement an animated testimonial slider featuring client photos, names, review texts, and star ratings.
- Contact Form: Include a contact form with name, email, and message fields, along with Instagram and WhatsApp buttons.

## Style Guidelines:

- Background color: Deep charcoal (#121212) to evoke a luxury dark theme.
- Primary color: Muted gold (#B8860B) for highlights and accents, inspired by luxury and elegance. The brightness of the primary allows good contrast against the dark background.
- Accent color: Subtle golden-yellow (#FFD700) as a bright pop to draw the eye to important interactive elements such as button hover states.
- Body and headline font: 'Inter' (sans-serif) provides a clean and modern aesthetic suitable for both headings and body text.
- Implement a full-screen cinematic hero section, premium grid gallery, and glassmorphism cards for services.
- Use smooth scrolling, liquid button hover effects, fade-in transitions, and animated skill bars to create a premium UI.
- Add soft glowing effects, subtle moving light streaks, and a cinematic blur effect in the background for a high-end creative studio feel.
